# HUB Lighting Finder

Web εφαρμογή Streamlit για αναζήτηση φωτιστικού από φωτογραφία μέσα σε PDF καταλόγους.

## Τοπική εκκίνηση
1. Εγκατάσταση Python 3.11.
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
4. Άνοιγμα της διεύθυνσης που εμφανίζεται στο terminal.

## Χρήση
1. Από το αριστερό μενού ανεβάζεις τους PDF καταλόγους.
2. Πατάς «Αποθήκευση PDF».
3. Πατάς «Δημιουργία ευρετηρίου».
4. Ανεβάζεις φωτογραφία φωτιστικού.
5. Η εφαρμογή επιστρέφει τις οπτικά πλησιέστερες σελίδες καταλόγων.

## Δημοσίευση
### Streamlit Community Cloud
Ανέβασε τον φάκελο σε ιδιωτικό GitHub repository και επίλεξε `app.py` ως main file.

### Azure App Service / Container Apps
Δημιούργησε container από το Dockerfile. Για μόνιμη αποθήκευση καταλόγων και ευρετηρίου, σύνδεσε persistent volume στους φακέλους `/app/catalogs` και `/app/data`.

## Σημείωση ακρίβειας
Η αναζήτηση γίνεται σε ολόκληρες σελίδες PDF. Σε σελίδες με πολλά προϊόντα, η αντιστοίχιση μπορεί να είναι λιγότερο ακριβής. Επόμενη παραγωγική βελτίωση είναι αυτόματη αποκοπή κάθε προϊόντος και σύνδεση με καθαρό κωδικό SKU.
